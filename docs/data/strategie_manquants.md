# Stratégie de valeurs manquantes

Décision écrite, par colonne et par usage. Les taux de manquants sont mesurés sur le parquet brut Open Food Facts, avant tout nettoyage (4 636 471 produits).

Appliquée par `cleaning.clean()` : la stratégie par défaut est `DEFAULT_MISSING_STRATEGY` (règle 11, `missing_strategy`), les autres décisions sont portées par les règles numérotées. Vocabulaire fermé : `keep`, `flag`, `constant:<valeur>`, `drop_column`, `median_by_group`, `mode`, combinables avec « + ». Une décision inconnue lève `ValueError`. `median_by_group` et `mode` sont reconnues mais **non appliquées** : l'imputation statistique appartient au pipeline ML, après le split.

| colonne | usage | manquants | décision | pourquoi |
|---|---|---|---|---|
| code | identifiant du produit, base, substitution | non mesuré | espaces retirés ; lignes sans code (NULL ou vide) écartées ; une fiche par code : la plus complète (completeness), puis la plus récente (last_modified_t, colonne conservée), puis la première rencontrée | un code identifie un produit : les doublons faussent les comptes et la clé unique de la base |
| allergens | affichage, assistant | 72 % | NULL, ou chaîne vide sans ingrédients → NA + drapeau allergens_missing ; chaîne vide avec ingrédients → « aucun allergène déclaré » ; jamais imputer ni prédire ; l'assistant répond « information non disponible » si NA | sans ingrédients, l'absence d'allergène ne peut pas être affirmée (manque quasi identique à ingredients_text) ; un allergène inventé ou omis est un risque pour l'utilisateur ; il n'entre pas dans le calcul du Nutri-Score |
| brands | affichage, substitution (même marque), assistant | 36,7 % | chaînes vides → NULL (NULLIF à la création, et règle 2 `normalize_texts`) ; variantes de casse d'une même marque ramenées à la graphie la plus fréquente ; garder NA + drapeau brands_missing ; « inconnue » à l'affichage seulement | aucune valeur plausible à inventer ; 108 709 chaînes vides s'ajoutaient aux NULL et auraient échappé au drapeau ; une marque écrite de plusieurs façons fausserait le top des marques et la substitution « même marque » |
| product_name | affichage, assistant | 6,0 % | garder NA + drapeau product_name_missing ; « nom non renseigné » à l'affichage seulement ; seul le premier nom de la liste (première langue) est conservé ; noms tout en majuscules → majuscule initiale puis minuscules (sigles de moins de 4 lettres conservés) ; jamais imputé | aucun nom plausible à inventer ; sans nom, le produit reste utilisable pour le score et la substitution ; un nom en capitales est illisible à l'affichage |
| categories_tags | substitution, features ML (food_groups_tag_1), assistant | 59,8 % | règle métier : inclassable si vide (NULL ou liste vide) → supprimer la ligne ; jamais imputée | sans catégorie ni groupe alimentaire, impossible de comparer un produit à un « même rayon » ; tous les produits sans catégorie ont aussi food_groups_tag_1 NULL, donc tester les deux colonnes est équivalent ; main_category ne récupère que 4 352 produits (0,09 %) et n'est pas retenue comme repli |
| main_category | affichage | non mesuré | gardée telle quelle, sans drapeau ; jamais imputée ; non utilisée comme repli de categories_tags | informative à l'affichage, mais trop peu de produits en profitent pour servir de repli (4 352, soit 0,09 %) |
| food_groups_tag_1 | substitution (même groupe alimentaire), groupe de la médiane | 68,5 % | garder NA dans le DataFrame nettoyé, jamais imputée ; à l'insertion en base, un rayon manquant devient `unknown` (aisles.aisle_code), comme l'exige le TP ; sert de groupe pour la médiane (énergie, fat, protéines) dans le pipeline ML ; un NULL, ou un groupe absent du train, reçoit la médiane globale du train | premier élément de food_groups_tags seulement ; aucune valeur plausible à inventer ; le taux est mesuré avant la suppression des produits sans catégorie, qui retire tous ces NULL sauf 403 071 produits qui ont des catégories mais pas de groupe ; la base a besoin d'un rayon pour chaque produit (clé étrangère), d'où `unknown` |
| completeness | analyse interne (justification du MAR, départage des doublons), features ML | 0 % | garder telle quelle, non exposée dans l'application | mesure le remplissage de la fiche, partiellement redondante avec les drapeaux _missing ; valeurs jusqu'à 1,1 (0,36 % > 1), conservées car elles ne sont pas aberrantes |
| last_modified_t | départage des doublons (la plus récente) | non mesuré | gardée telle quelle (entier, BIGINT en base), non exposée dans l'application | sert uniquement à choisir la fiche à conserver quand deux fiches ont la même complétude |
| ingredients_text | assistant, features texte | 72 % | garder NA + drapeau ingredients_text_missing | aucune valeur plausible à inventer ; aucune chaîne vide constatée |
| nova_group | affichage | 75 % | garder NA + drapeau nova_group_missing | dérivée des ingrédients : si l'ingrédient est absent, 98,5 % de chances que nova soit absent aussi |
| nutriscore_score / nutriscore_grade | cible du modèle, affichage | 70,2 % | garder ; « unknown » et « not-applicable » → NA ; drapeau grade_not_applicable ; jamais imputer ; le score n'est pas borné par une règle : étendue observée −17 à 55, contrôlée par le schéma pandera et la base ; 2 849 scores hors −15 à 40 (environ 0,2 %), laissés tels quels et à examiner à l'analyse exploratoire | une cible imputée est une cible inventée ; un score extrême n'est pas forcément faux, seul un calcul de score dirait lequel l'est |
| energy_kcal_100g | score, affichage, features ML, substitution, assistant | 28 % | dans l'ordre des règles : (7) si le rapport kJ / kcal sort de [3,9 ; 4,5] (kcal et kJ positives) → kcal = kJ / 4,184 ; (8) hors [0, 900] → NA (energy_kj_100g borné à [0 ; 3 765,6]) ; (13) énergie nulle avec macros, ou écart > 50 % avec le calcul 4/4/9 (calcul ≥ 50 kcal) → recalcul 4/4/9 et kJ réalignés, sauf boissons alcoolisées ; si le recalcul est impossible (macro manquante, calcul hors [0, 900]) → kcal ET kJ à NA ; (15) kcal manquantes : kJ / 4,184, sinon 4/4/9 ; drapeau energy_kcal_100g_missing posé après ces dérivations (vrai = manquante après dérivation) ; reste → médiane par food_groups_tag_1 calculée sur le train uniquement, après le split, dans le pipeline ML | dérivable avant d'être devinée ; la conversion kJ est exacte, le 4/4/9 est approché (il ignore fibres, polyols et alcool) ; kcal et kJ sont invalidées ensemble, sinon la règle 15 referait les kcal depuis des kJ douteux ; la médiane n'intervient qu'en dernier recours |
| sugars_100g | score, features ML, affichage, assistant | 32 % | hors [0, 100] → NA ; sucres > glucides + 0,5 → NA ; garder NA + drapeau sugars_100g_missing ; jamais imputer | une valeur inventée fausserait le score ; aucune formule exacte ne permet de les dériver ; manque MAR lié à la complétude de la fiche et à la catégorie de nourriture |
| salt_100g / sodium_100g | score, features ML, substitution, affichage, assistant | 37 % | dans l'ordre des règles : (6) si les deux sont présents et abs(sel − 2,5 × sodium) > 0,1, sodium recalculé depuis le sel ; si un seul est présent, l'autre est dérivé (sel = sodium × 2,5, et inverse) ; (8) ensuite, sel hors [0, 100] et sodium hors [0, 40] → NA | relation exacte, zéro risque ; le sodium représente environ 40 % de la masse du sel, d'où la borne à 40 ; le sel fait référence. Conséquence connue de l'ordre unités puis bornes (celui du TP) : un sel aberrant (5 000 g) avec un sodium valide donne un sodium recalculé aberrant, donc sel et sodium à NA ; on perd un sodium correct, faute de pouvoir savoir lequel des deux est faux |
| fiber_100g | score, features ML, substitution, affichage, assistant | 62 % | hors [0, 100] → NA ; garder NA + drapeau fiber_100g_missing ; jamais imputer | MNAR : l'absence veut souvent dire « pas de fibres déclarées », mais on ne distingue pas un vrai zéro d'un oubli ; pas d'invention de valeur pour une composante du Nutri-Score ; le drapeau garde l'information |
| fruits_vegetables_legumes_100g | score, features ML, substitution, affichage, assistant | 83 % | hors [0, 100] → NA ; garder NA + drapeau fruits_vegetables_legumes_100g_missing ; jamais imputer ; affichage « non renseigné », jamais 0 | colonne renseignée pour une minorité de produits ; l'absence ne veut pas dire 0 % (un produit peut contenir des fruits ou légumes sans que le fabricant l'ait déclaré) ; un 0 inventé fausserait une composante favorable du score |
| serving_size | sel par portion (affichage) | 68 % | à garder, jamais imputée ; si NA, affichage des valeurs pour 100 g | la portion est propre à chaque produit, aucune valeur de repli plausible ; utile quand elle est présente |
| fat_100g | features ML, contrôle de cohérence, substitution, affichage, assistant | 28 % | hors [0, 100] → NA ; garder NA + drapeau fat_100g_missing ; borne haute pour les saturées ; reconstitution (énergie − 4 × protéines − 4 × glucides) / 9 testée puis abandonnée ; reste → médiane par food_groups_tag_1 calculée sur le train uniquement, après le split, dans le pipeline ML | MAR : suit la complétude du tableau nutritionnel ; reconstitution applicable à 0,16 % des lignes seulement, erreur médiane de 0,4 g, gain négligeable pour une approximation |
| proteins_100g | score, features ML, affichage, substitution, assistant | 28 % | hors [0, 100] → NA ; garder NA + drapeau proteins_100g_missing ; reste → médiane par food_groups_tag_1 calculée sur le train uniquement, après le split, dans le pipeline ML | MAR : manque groupé avec la complétude de la fiche ; composante favorable du Nutri-Score ; aucune dérivation exacte possible, médiane assumée comme pour l'énergie et le fat |
| carbohydrates_100g | features ML, contrôle de cohérence, substitution, affichage, assistant | 28 % | hors [0, 100] (dont > 100) → NA ; garder NA + drapeau carbohydrates_100g_missing ; borne haute pour sugars_100g ; jamais imputée | utile au profil nutritionnel ; une valeur inventée fausserait les contrôles de cohérence |
| saturated_fat_100g | score, features ML, affichage, substitution, assistant | 34 % | hors [0, 100] → NA ; saturées > fat + 0,5 → NA ; si fat_100g < 0,5 g et saturées NA → 0 ; garder NA + drapeau saturated_fat_100g_missing (posé avant le passage à 0) ; sinon jamais imputer ; score non calculable si NA | composante directe du Nutri-Score, une valeur inventée fausserait le score ; les saturées sont une sous-partie des lipides : fat < 0,5 g implique saturées < 0,5 g (arrondi d'étiquetage à 0) |
| produit sans aucun nutriment clé | — | 26,7 % | supprimer la ligne si toutes les composantes du score sont manquantes : energy_kcal_100g, energy_kj_100g, saturated_fat_100g, sugars_100g, proteins_100g, salt_100g, sodium_100g (règle 14, après la correction de l'énergie et avant la dérivation des kcal manquantes) | inutilisable pour le score et la substitution ; placée avant la règle 15 pour que la dérivation des kcal ne fasse pas revivre une ligne vide |

## Drapeaux

Les colonnes `<colonne>_missing` valent vrai quand la valeur est manquante. Elles sont posées dans le DataFrame nettoyé : `allergens_missing`, `brands_missing`, `carbohydrates_100g_missing`, `energy_kcal_100g_missing`, `fat_100g_missing`, `fiber_100g_missing`, `fruits_vegetables_legumes_100g_missing`, `grade_not_applicable`, `ingredients_text_missing`, `nova_group_missing`, `product_name_missing`, `proteins_100g_missing`, `saturated_fat_100g_missing`, `sugars_100g_missing`.

Seuls trois sont **stockés en base** (table `products` ou `nutrients`) : `grade_not_applicable`, `saturated_fat_100g_missing` et `energy_kcal_100g_missing`. Les autres se déduisent d'un simple `IS NULL` sur la colonne concernée.
